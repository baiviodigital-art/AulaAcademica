# Aula Académica · Derecho Laboral

Aula de estudio de Derecho Laboral (ADE): temas 1–6, banco de preguntas, cuaderno de errores, simulador y planificador.

- El progreso se guarda solo en el navegador donde se usa. Usa "Fuentes y datos → Exportar" para hacer copias.
- Esta versión pública no incluye el texto de los temas: las referencias indican archivo y página para consultarlos en el material de la asignatura.
- Las preguntas son generadas para entrenar y las notas son orientativas.
